## Web client for Jellyfin

Laravel 13 + Inertia v3 + React 19 + TypeScript + Tailwind v4 + shadcn/ui. A client only: no own users, no admin — the dashboard, profile settings, music, Live TV, books and playlists open in Jellyfin's built-in web client (`App\Jellyfin\BuiltInClient`, routes `/dashboard`, `/settings`, external library links). UI text and comments are in Russian; commit messages in English.

- Everything Jellyfin goes through `App\Jellyfin\Jellyfin` (bound per request in `AppServiceProvider` with the signed-in user's token and the browser's `DeviceId` cookie). It returns Jellyfin's PascalCase arrays as is; resources in `app/Http/Resources` (`ItemCard`, `ItemDetail`, `EpisodeCard`, `LibraryCard`) shape them for pages — pass them to Inertia via `->resolve()`. Errors: 401 → `SessionExpired` (logs out, redirect or JSON 401), 404/403 → HTTP exceptions, network/5xx → `JellyfinUnavailable` (Inertia `error` page, 503). The `Authorization` header values are URL-encoded (`ClientIdentity`) — Jellyfin decodes them, and the client name is Cyrillic.
- Auth: Laravel's `auth`/`guest` middleware with a session-backed provider (`App\Jellyfin\SessionUserProvider`, driver `jellyfin` in `config/auth.php`); `JellyfinUser` is a readonly value object stored in the session (`LoginController::signIn`). Quick Connect both ways: sign in with a code (`QuickConnectLoginController`, the secret stays in the session, the login page polls `check`) and authorize another device (`QuickConnectController`).
- Images and video go straight from Jellyfin to the browser via `JELLYFIN_PUBLIC_URL` (`App\Jellyfin\Image`; user avatars use `/UserImage`). Jellyfin 12 accepts a token in URLs only as `ApiKey=` (not `api_key=`).
- Libraries: `LibraryKind` — movies/tvshows are recursive poster grids, mixed/homevideos/boxsets/no type are browsed by folder, everything else is external. Grids page through `/Items` via `App\Jellyfin\ItemPage` (a `LengthAwarePaginator`, so `Inertia::scroll()` + `<InfiniteScroll>` work). `ItemController::show` dispatches by `Type` (Series, Person, folders, videos; Season redirects to its series).
- Shared props (`HandleInertiaRequests`): `auth.user`, `builtIn` links, `libraries` as `Inertia::once` (loaded once per page load, `rescue`d so error pages render when Jellyfin is down). Logout is `Inertia::location` — a full reload drops the once-cache.
- Player (`resources/js/components/player.tsx`): the page `watch` only gets metadata; the stream is requested from the browser (`POST /watch/{item}/playback`, `PlaybackController::store`) with the codecs it reports (`lib/capabilities.ts`) → `DeviceProfile::build` → `/Items/{id}/PlaybackInfo` → `PlaybackSource`. Direct play uses the extensionless `/Videos/{id}/stream?static=true` (a `.mov` extension makes Jellyfin send `video/quicktime`); everything else is HLS via `TranscodingUrl` + lazily imported hls.js. HEVC/AV1 come first in the transcoding profile so Jellyfin copies the video stream when only the container or audio is incompatible — this server cannot transcode 4K HEVC. Always send `MediaSourceId` (the player passes the current source's; the server falls back to the item id) — Jellyfin applies `AudioStreamIndex`/`SubtitleStreamIndex` only when the request names the media source (`MediaInfoHelper`), otherwise silently plays the defaults. Always send `SubtitleStreamIndex` (-1 unless the user picked an image subtitle to burn in), or the server may burn in a default PGS track. Text subtitles are fetched as VTT and rendered by the player. If direct play fails in the browser, the player retries once with `directPlay: false`. Browsers play only a file's default audio track, so unless the browser exposes `audioTracks` (Safari — then tracks switch in place, `switchNativeAudio`) the profile carries a `VideoAudio` `IsSecondaryAudio = false` condition and Jellyfin remuxes with the chosen track. `PlaybackSource.audioIndex` is the track actually playing (`AudioStreamIndex` from `TranscodingUrl`), and the UI shows that, not the requested one. Track switches (`reload`) freeze the current frame on a `<canvas>` with a small indicator, keep controls and play/pause state, and swap on `canplay`; the report hook remembers the last real position so `stop` never sends 0. For HDR sources Jellyfin's HLS master has two variants — the stream-copied one (HDR, same `VideoCodec` as the transcoding URL) and an H.264 SDR fallback that means a full transcode; hls.js drops non-SDR variants on displays without `dynamic-range: high`, so the player sets `videoPreference` to allow all ranges and pins the level whose `VideoCodec` matches the master URL (`MANIFEST_PARSED`). Resume uses a `#t=` media fragment, not a seek in `loadedmetadata`.
- Playback reporting (`hooks/use-playback-report.ts` → `POST /playback/{start|progress|stop}`, `PlaybackEvent` enum binding) keeps "Continue watching" in Jellyfin; `stop` uses `fetch(..., {keepalive})`. Player JSON requests (`lib/api.ts`) send `X-XSRF-TOKEN` from the `XSRF-TOKEN` cookie, never a `<meta>` token — that one goes stale when the session changes without a full reload (419).
- Frontend routes come from Wayfinder (`@/routes`, `@/actions`; generated, git-ignored). The layout is picked in `app.tsx` (`auth/*` → `AuthLayout`, `watch` → none); pages with a full-bleed backdrop set `Page.layout = { overlay: true }` and keep the content after the hero `relative` (the absolute backdrop overlaps it otherwise).
- Dev: `composer dev` (or `php artisan serve` + `npm run dev`); the public demo server works as a backend (`https://demo.jellyfin.org/stable`, user `demo`, no password — shared, so its resume positions change under you). Checks: `composer test` (pint, phpstan level 7, Pest), `npm run check`, `npm run types:check`, `npm run build`.
- Deploy: image `ghcr.io/kamabyte/jellyfin-web` (GitHub Actions `image.yml`; `Dockerfile` — the build stage needs PHP for Wayfinder), Dokploy stack from `deploy/dokploy/compose.yml`, `deploy/dokploy/deploy.sh` (per-install targets in git-ignored `deploy/dokploy/targets/<name>.env`; sets `IMAGE_TAG=sha-…`, checks `/up`; `deploy.sh <commit>` rolls back). The repository is public: never commit hostnames, IPs or keys — they belong in `targets/` or the stack's Environment. CI: `tests.yml` runs `composer setup && composer ci:check`. User-facing docs are in Russian (`README.md`, `docs/`, `deploy/dokploy/README.md`).

## Code style (PHP)

- One controller per resource; single-page controllers are invokable. Services and the request are injected into the method.
- Validation: one field inline with `$request->validate()`; two or more — a FormRequest with typed accessors (`LoginRequest`, `PlaybackRequest`, `ReportPlaybackRequest`).
- Flat returns: build data into variables first, then a flat array for `Inertia::render()` / `response()->json()`. Props that a partial reload may skip are closures (see `HomeController`).
- Typed class constants and return types on every method. `final readonly` value objects (`JellyfinUser`, `PlaybackSource`, `ClientIdentity`), dedicated exceptions next to the service (`InvalidCredentials`, `PlaybackUnavailable`).
- Toasts: `App\Support\Toast::success()` / `::error()`, never `Inertia::flash('toast', ...)` directly.
- Tests are Pest functions with `Http::fake()`; `Http::preventStrayRequests()` is on in `Tests\TestCase`. Helpers (`signIn()`, `jfItem()`, `jfList()`, `inertiaHeaders()`) are in `tests/Pest.php`.
- Run `vendor/bin/pint --dirty` before committing.
