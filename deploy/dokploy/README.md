# Развёртывание в Dokploy

Приложение разворачивается как стек Compose (источник Raw) из файла
[`compose.yml`](compose.yml). Допускается несколько установок, например на разных
серверах: у каждой установки собственный стек и собственная вкладка Environment.

    push ──► GitHub Actions ──► ghcr.io/kamabyte/jellyfin-web:{sha-…, latest}
                                          │
               Dokploy → стек jellyfin-web → Deploy ──► web

Стек состоит из одного сервиса `web` (Laravel и nginx). При запуске выполняются
миграции и кеширование конфигурации. Порт наружу не публикуется: приложение
открывается через домен, назначенный стеку в Dokploy (вкладка Domains, порт 8080).

## Подготовка сервера

1. Создайте каталог для базы данных (сессии и кеш):

       sudo mkdir -p /srv/jellyfin-web/state/database
       sudo chown -R 33:33 /srv/jellyfin-web/state

2. В Dokploy создайте проект и стек `jellyfin-web` (тип Compose, источник Raw).

3. Во вкладке Environment стека задайте переменные:

    | Переменная            | Значение                                                                                                  |
    | --------------------- | --------------------------------------------------------------------------------------------------------- |
    | `APP_KEY`             | ключ приложения: `php artisan key:generate --show`                                                        |
    | `APP_URL`             | адрес приложения, например `https://kino.example.lan`                                                     |
    | `JELLYFIN_PUBLIC_URL` | адрес Jellyfin, доступный из браузера                                                                     |
    | `JELLYFIN_URL`        | адрес Jellyfin для контейнера; по умолчанию `http://host.docker.internal:8096` (Jellyfin на том же хосте) |
    | `IMAGE_TAG`           | тег образа `sha-…`; устанавливается скриптом выкатки                                                      |

4. Во вкладке Domains назначьте домен, порт контейнера — 8080. Для доменов
   с `https://` включите HTTPS и Let's Encrypt; заголовкам прокси Traefik
   приложение доверяет.

### Сеть Jellyfin

Запросы контейнера приходят в Jellyfin из сети Docker. Если эта сеть не входит
в список локальных сетей Jellyfin («Панель управления → Сеть → Локальные сети»),
к ним применяется ограничение битрейта для удалённых клиентов, и Jellyfin начинает
перекодировать видео. Добавьте подсеть Docker в список локальных сетей либо
оставьте список пустым.

## Выкатка

Выкатка выполняется с рабочего компьютера одной командой через API Dokploy.
Скрипт [`deploy.sh`](deploy.sh) дожидается сборки образа коммита в GitHub Actions,
затем на каждой установке загружает `compose.yml` в стек, устанавливает
`IMAGE_TAG=sha-<коммит>`, запускает Deploy и проверяет ответ `/up`. Установки
обрабатываются последовательно; при первой ошибке скрипт останавливается.
GitHub не обращается к серверам, секреты в Actions не хранятся.

    git push && deploy/dokploy/deploy.sh   # origin/main на все установки
    deploy/dokploy/deploy.sh <коммит>      # закрепить или откатить на <коммит>
    deploy/dokploy/deploy.sh -t home       # только одна установка

Отправка изменений сама по себе ничего не выкатывает. По завершении скрипт
выводит команду отката на предыдущий коммит.

Для работы скрипта требуются `gh` (с авторизацией), `jq` и `curl`.

### Описание установки

Каждая установка описывается файлом `deploy/dokploy/targets/<имя>.env`.
Каталог `targets` исключён из репозитория (`.gitignore`): в нём находятся
адреса серверов.

    DOKPLOY_URL=http://dokploy.example.lan   # Dokploy в локальной сети, или
    DOKPLOY_SSH=root@203.0.113.10            # через ssh-туннель к его localhost:3000
    # KEYCHAIN=dokploy-api-<имя>  PROJECT=jellyfin-web  STACK=jellyfin-web — по умолчанию

Если Dokploy доступен по публичному адресу без TLS, используйте только `DOKPLOY_SSH`:
в противном случае API-ключ будет передан по сети в открытом виде. Адрес для проверки
`/up` скрипт берёт из `APP_URL` во вкладке Environment стека.

API-ключ установки создаётся в Dokploy («Settings → Profile → API/CLI») и сохраняется
в связке ключей macOS:

    security add-generic-password -U -a "$USER" -s dokploy-api-<имя> -w

### Выкатка вручную

1. Отправьте изменения: GitHub Actions соберёт образы `sha-<коммит>` (любая ветка)
   и `latest` (ветка `main`).
2. В Dokploy, в стеке `jellyfin-web` → Environment, установите `IMAGE_TAG=sha-…`.
3. Нажмите Deploy.

Откат выполняется так же — указанием прежнего значения `IMAGE_TAG`.

## Данные

| Путь на хосте                      | Назначение                              |
| ---------------------------------- | --------------------------------------- |
| `/srv/jellyfin-web/state/database` | база SQLite: сессии пользователей и кеш |

Медиатека, метаданные и история просмотров хранятся в Jellyfin. Потеря базы
приложения приводит лишь к необходимости повторного входа.
